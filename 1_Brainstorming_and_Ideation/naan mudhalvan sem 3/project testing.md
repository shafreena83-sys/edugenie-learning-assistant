# 🧞 EduGenie – Learning Assistant

> Your personal AI-powered study companion that explains concepts, answers doubts, and helps you learn at your own pace.

---

## 📖 Overview

**EduGenie** is a learning assistant designed to make studying simpler and more interactive. Students can ask questions, get clear step-by-step explanations, practice with quizzes, and track their learning progress — all in one place.

## ✨ Features

- 💬 **Ask Doubts** – Get instant, easy-to-understand answers to any topic
- 📚 **Concept Explanations** – Step-by-step breakdowns with examples
- 📝 **Quiz Generator** – Practice questions to test your understanding
- 🗂️ **Notes Summarizer** – Turn long notes into short, revisable summaries
- 📈 **Progress Tracking** – See what you've learned and what needs revision
- 🌐 **Multi-language Support** – Learn in your preferred language *(optional)*

## 🚀 Getting Started

### Prerequisites

- Python 3.9+ *(or Node.js 18+, based on your stack)*
- Git
- An API key for the AI service you use

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/edugenie.git
cd edugenie

# 2. Install dependencies
pip install -r requirements.txt

# 3. Set up environment variables
cp .env.example .env
# Add your API key inside .env

# 4. Run the application
python src/main.py
```

## 💡 Usage

1. Start the application.
2. Type your question or choose a topic (e.g., *"Explain photosynthesis"*).
3. Read the explanation, then take a quick quiz to check your understanding.
4. Review your progress and revise weak areas.

**Example**

```
You:      Explain Newton's second law in simple words.
EduGenie: Newton's second law says that force = mass × acceleration ...
```
